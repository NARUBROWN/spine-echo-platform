# spine-echo-platform v0.2.0 전환

Spine v0.7.0 계약을 기준으로 검증합니다. Preview는 Preview 코어, RC는 RC 코어, 정식은 정식 코어를 go.mod에 명시합니다. 패키지 버전 번호는 코어와 독립적입니다.

기존 정식 v0.1.0 태그와 그 의존성은 변경하지 않습니다. 새 채널을 사용하려면 코어와 플랫폼의 검증된 버전 조합을 함께 선택하세요.

## HTTP v3 Preview 전환

이 작업 소스의 후보는 Echo `v0.2.0-preview.2`와 코어 `v0.7.0-preview.3`입니다. 공개된 `v0.2.0-preview.1`의 HTTP v2 구현과 소스 호환되지 않습니다. 후보 태그 발행과 공개 설치 검증은 아직 진행하지 않았습니다.

플랫폼은 `contract/http`의 원시 요청, 응답 출력과 서버 수명을 제공합니다. Spine DTO 바인딩과 multipart 파싱은 코어가 처리합니다. 입력에서 Echo Binder와 JSONSerializer를 호출하지 않으며, 사용자 입력 디코더는 표준 디코더 또는 native Echo 경로에서 사용합니다. 응답 serializer와 `WithEcho`의 native 경로 및 middleware는 유지합니다.

준비 결과의 `Handler()` 대신 `spine.NetHTTPHandler(prepared)`로 외부 서버용 handler를 얻습니다. 외부 서버 자체는 호출자가 종료하고 앱 자원은 `prepared.Close(ctx)`로 정리합니다.

## TLS 실행

`boot.HTTPOptions.TLS`에 인증서를 담은 `*tls.Config`를 지정합니다. 준비 기본값은 기존 `Serve(listener)`가 사용하며 실행 시 `httpcontract.WithTLS(config)`로 교체할 수 있습니다. `Serve`는 선택 인자를 받는 단일 공개 진입점입니다. nil TLS 기본값은 평문 HTTP이고, 명시적인 `WithTLS(nil)`은 오류입니다.

플랫폼은 native 훅 실행 전에 정적 인증서 구성을 검사합니다. TLS 리스너를 native 서버에 연결하며 새 요청 차단과 진행 요청 및 후처리 종료 대기 정책을 유지합니다. 외부 서버에 handler만 연결하면 TLS 실행은 외부 서버 소유입니다. HTTP 버전 선택과 ALPN 정책은 별도 검토 범위입니다.

인증서 로드와 실행 예시는 [README의 TLS 실행](../../README.md#tls-실행)을 참고하세요.
