# spine-echo-platform v0.2.1 전환

이 버전은 Spine `v0.7.2-preview.2`의 HTTP 요청 계약에 맞춰 Echo 통합 테스트를 갱신합니다. 테스트 핸들러는 일반 DTO 포인터 대신 `input.Body[T]`, `input.Query[T]`, `input.Header[T]`를 선언합니다. Echo 어댑터 구현은 그대로입니다.

앱에서 코어를 올릴 때 기존 HTTP 핸들러가 일반 DTO 포인터를 받는다면 [코어 v0.7.2 전환 안내](https://github.com/NARUBROWN/spine/blob/v0.7.2-preview.2/docs/migration/v0.7.2.md)에 따라 입력 래퍼를 명시하세요.
